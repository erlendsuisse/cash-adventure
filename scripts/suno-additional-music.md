Generate these 5 new tracks in Suno to add variety. Place them in `src/assets/music/chapter1/`

## 1. merchant-gambit-alt.mp3

**Mood**: Alternative variation of merchant trading theme - more upbeat, celebratory

**Suno Prompt**:
```

Mood: Celebratory, energetic merchant activity. A successful trading day with multiple good deals happening. Uplifting and profitable. Different from the main merchant theme but complementary.

Style: Fantasy steampunk, instrumental only, no vocals. Upbeat, major key, celebratory tone.

Instruments: Bright strings, peppy woodwinds, rhythmic percussion (drums, bells), cheerful brass. Energetic and optimistic soundscape.

Tempo: Brisk and lively. Loopable - ends smoothly and can repeat seamlessly.

Quality: Atmospheric, immersive, game-ready background music. Professional production. 2.5 minutes exactly.
```

## After Generation

1. Download all 5 tracks from Suno
2. Place in `src/assets/music/chapter1/` with exact filenames:
   - merchant-gambit-alt.mp3
   - exploration-calm.mp3
   - tension-rising.mp3
   - danger-imminent.mp3
   - victory-celebration.mp3
3. Run: `npm run build && npm run dev`
4. Music will now rotate and vary based on game state! 🎵
